🔒 Autenticação Google

Como obter o OAuth Client ID ▾
  1. Acesse o Google Cloud Console e abra o mesmo projeto da sua API Key
  2. Ative a YouTube Analytics API (APIs e Serviços → Biblioteca)
  3. Vá em APIs e Serviços → Credenciais → Criar credencial → ID do cliente OAuth 2.0
  4. Tipo: Aplicativo da Web
  5. Em Origens JavaScript autorizadas, adicione:
    https://SEU_USUARIO.github.io e http://localhost
  6. Copie o ID do cliente e cole acima
